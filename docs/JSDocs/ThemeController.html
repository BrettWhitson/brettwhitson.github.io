ThemeController - Manages light/dark theme switching

Follows the operating system's color scheme until the visitor picks a theme with the toggle; that explicit choice is saved and wins from then on. The initial saved theme is applied by an inline script in the document head, before first paint.

Example
const theme = new ThemeController();
theme.init();
window.addEventListener("themechange", (e) => console.log(e.detail.theme));
